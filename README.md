# 🗣️ aitalki

**AI Speaking iTalki** — Your personal speaking coach!  

🌐 Deployed at: [aitalki.app](https://aitalki.app)

---

## 🚀 What is aitalki?

aitalki is an AI-powered speaking companion focused **exclusively on conversation and pronunciation** practice — think of it like your own virtual language coach.

Forget textbooks — just talk!

---

## ✨ Features

- 🎙️ **Speak with an AI teacher** in real-time  
- 🗂️ Choose what to focus on: grammar, pronunciation, vocabulary  
- 💬 Get corrections, hints, and tips while you speak  
- 📊 Receive a conversation summary & improvement recommendations at the end  
- ⏰ 1-hour focused lessons — no endless rambling

---

## 🔨 Tech Stack

- ⚙️ Python FastAPI backend  
- ☁️ Deployed on Hetzner with CDK Terraform (TypeScript)  
- 🧠 Gemini Voice for AI conversation  
- 🔊 Google TTS for natural audio replies

## ⚡ Workflow

1. User sends audio 🎧  
2. Gemini processes audio + returns text 🧠  
3. Google TTS turns response into speech 🔊  
4. User receives AI audio reply 🔁
